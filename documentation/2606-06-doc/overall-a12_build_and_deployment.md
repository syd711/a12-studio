# overall a12_build_and_deployment

Build and Deployment
This section of our documentation is intended for DevOps users. It includes documentation on how
to build and deploy your A12-based application.
The Helm A12 Stack is a comprehensive collection of Helm charts designed for seamless
deployment of A12-based applications on Kubernetes. The primary goal of our Helm charts is to
enable easy deployment with minimal configuration while offering flexibility for customization.
The A12 Build and Deployment Pipelines are a collection of pre-made declarative Jenkins pipelines
designed to assist in building your A12-based application and deploying it on the mgm TPI Cluster
using the Helm A12 Stack charts. Partner users can inherit these configurations and adapt them to
match their specific infrastructure setup.
