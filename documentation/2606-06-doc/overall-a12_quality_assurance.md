# overall a12_quality_assurance

Quality Assurance
A12 provides a set of efficient solutions that make test automation of A12 applications an enjoyable
and rewarding endeavor.
A12 provides a model-driven test automation tool (ATA) in its test automation catalogue that
significantly accelerates end-to-end test automation in A12 projects. This efficient tool not only
generates the test code needed for test automation quickly and reliably but also takes over the
tedious task of filling and checking all forms in your A12 application
Moreover, if these forms change during the development process, the A12 test automation tool
easily regenerates new test code, so that tests can run immediately.
Thanks to the A12 test automation tool, any A12 application, whether newly modelled or
remodeled, can automatically be tested immediately, allowing to detect implementation and
integration issues in added custom code very quickly.
Altogether, the model-driven ATA saves considerable implementation and maintenance overhead
in test automation. It simplifies and accelerates the test automation of A12 applications
significantly.
If you are interested in learning more about End2End test automation in A12, you are welcome to
attend the A12 QA - Automated Testing Training. Moreover, If you are interested in benefiting from
the A12 test automation solution catalog in your project, please contact the mgm Quality Team by
email: qualityteam-pm@mgm-tp.com.
User documentation for the ATA will soon be available here.
The Test Data Generator (TDG) generates technical testdata based on Document Models. In addition,
it can be used for mathematical consistency checks of them.
