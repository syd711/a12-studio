# overall a12_modeling

Modeling
This section of the documentation is designed for business analysts using A12
but is also valuable for developers looking to understand how models are
created. If you’re new to A12, we recommend starting with the Video
introduction to Modeling in A12.
Here is a brief explanation of what you can find in this section of the documentation.
Accessing A12
This section includes two concise guides: the Quick Start Guide, which provides an overview for
getting started with the A12 Modeling Environment, and Installing A12, which offers step-by-step
instructions for installation.
Modeling Environment
This section provides a comprehensive guide to the core tools of the A12 Modeling Environment:
the Model Editor (SME), for creating and editing models, and the Preview App, for testing and
refining your applications in a local environment. Additionally, the manual for the Cloud Modeling
Environment can be found here.
Modeling
This section begins with a Model Overview, which introduces the various model types created and
edited in SME, followed by a guideline for modelers on Model Naming Conventions to help ensure
consistency and clarity.
The Data Modeling subsection provides detailed documentation for model types and tools,
including:
• Document Modeling and Relationship Modeling.
• Guides for Kernel Language, Modeling Heterogeneous Data and using the Model Graph
Diagram.
• Combination Modeling and Mapping Modeling
• Query Modeling and Workspace Data.
The UI Modeling subsection provides documentation about our UI model types and their
associated tooling, including:
• Form Modeling, Overview Modeling and Tree Modeling.
• A dedicated guide for the modeling of relationship UI components, described in Form Modeling
- Binding.
• Documentation on Content Modeling.
This section also includes guides for advanced topics, such as Workflow Modeling, Application
Modeling and using the Print Model Editor to design and manage formatted document outputs.

The Preview App, as part of the Modeling Environment, offers comprehensive features such as
Modeling Support for Role Based Access Control for managing users and roles of an application.
Additionally, modelers can leverage the specialized model type described in Master Detail
Modeling.
Tutorials
Last but not least, step-by-step tutorials are available to help you learn how to model some of the
more complex features of A12.
Video introduction to Modeling in A12
This video is a short introduction to the A12 platform and outlines the benefits of modeling in
general. Our aim is to give a brief outline of some of the features that are available in A12 to
modelers and business analysts and to show you what you can achieve through modeling alone
with A12. We show these features with the help of one of the sample workspaces that come with the
A12 installer. This application is fully modeled without any additional development.
This introduction targets everyone who is curious about A12 and would like to get some insight into
the possibilities that it offers.
