# overall a12_development

Development
This documentation section contains all necessary information to start development with the A12
Platform.
The Get Started section is our starting point. There, you can find everything about getting A12
artifacts as well as our Project Template. You can find our step-by-step, self-paced tutorials in the
Tutorials section, where you will learn how to develop with A12.
The Components section contains the developer documentation for all components that make up
the A12 platform. To migrate to the latest major version of the A12 platform, have a look at the
Migrating to latest A12 section.
