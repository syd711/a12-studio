# overall dev_tutorial_frontend_intro

Frontend Tutorial
WARNING This tutorial refers to an older version of A12 (2025.06-ext5). An updated
version is currently in progress and will be available as soon as possible.
NOTE This tutorial uses A12 version 2025.06-ext5 and is based on the Project Template
version 202506.5.1.
Prerequisites
For this frontend tutorial, prior knowledge of the following technologies is necessary:
• TypeScript
• React
• Redux
◦ Redux-Saga
The tutorial also assumes you have the following programs available:
• Text editor / IDE
• A12 Modeling Environment in version 2025.06-ext5
• redux-devtools
We are extending the CRM system, which has been created and implemented in the previous
tutorials. If you want to know how it was implemented, you can check them out.
Overview
This tutorial serves as an introduction into customizing the frontend of an A12 application.
The following aspects will be covered in the tasks:
• Task 1: Application Frame
• Task 2: Overview Customization
• Task 3: Form Customization
• Task 4: Data in Activities
• Task 5: Middleware and Saga
• Task 6: Unit Testing
