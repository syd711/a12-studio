# overall quick_start_guide

Get Started with Modeling
Welcome to the A12 Modeling Environment. By the end of this guide, you’ll
know how to access the tools included in your installation and explore the
delivered Sample Workspaces in both, the Simple Model Editor and the Preview
App.
Download and Install
To download and install the A12 Modeling Environment, please follow the instructions from
Installing A12.
What Is Included in the A12 Installation
When you install the A12 Modeling Environment, you’ll gain access to the following tools and
components:
• The Simple Model Editor: The SME is the primary tool for creating and editing models.
• The Preview App Control: A utility to manage the Preview App and workspaces. The Preview App
allows you to test your models in a locally running full stack application.
• Sample Workspaces: Pre-configured example workspaces that demonstrate A12’s modeling
capabilities and provide a starting point for your own projects.
Additionally, you can find the Camunda Modeler to work with workflows models (bpmn & dmn)
and a link to the documentation.
