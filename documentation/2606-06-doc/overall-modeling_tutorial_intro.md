# overall modeling_tutorial_intro

Tutorials
Here you will find step-by-step tutorials to help you learn how to model some of the more complex
features of A12. Before attempting the specialists tutorials you should complete the A12 Modeling
Fundamentals training.
The following Tutorials are available in this section:
• Basic Modeling: focuses on modeling the most simple local application possible. Whilst this
tutorial has no prerequisites, it is designed to complement the A12 Fundamentals Training.
• Kernel Language: focuses on using the A12 Kernel Language to create complex validations and
computations.
• Heterogeneity Modeling: enables A12 modelers to group data so that you can create
heterogeneous lists of different types of data in a single overview.
• Relationship Modeling: will teach you how to link documents and why you might need to use
relationships in your project.
• Tree Modeling: explains how to model trees in A12 so that you can display an overview of your
data in a hierarchical structure.
• Put It All Together: focuses on using the skills learned in the Heterogeneity Modeling,
Relationship Modeling and Tree Modeling tutorials.
• Print Modeling: focuses on modeling with the Print Model Editor.
• Workflows Modeling: focuses on integrating BPMN and DMN Models into your Application.
