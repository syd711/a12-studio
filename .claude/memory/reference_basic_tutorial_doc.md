The A12 "Tutorial: Basic Modeling" (originally `C:\Users\matth\Downloads\basic-tutorial.pdf`) has been converted to markdown and lives at `docs/basic-tutorial.md` in this repo.

It walks through building a simple shopping-list app end-to-end using the Simple Model Editor: Document Model → Form Model → Overview Model → Master Detail Module Model → referencing it in `PreviewApp_AM` → local preview/deploy/test. Also includes a glossary of core A12 modeling terms (Control, Document Model, Field, Form Model, Master Detail Model, Overview Model, Preview App Control, Workspace, etc.).

Useful as a reference for the intended end-user workflow/terminology when comparing a12-studio's UI against SME's (see `docs/sme-reference-comparison.md` for the code-level comparison).

Note: figure/screenshot images from the PDF were not extracted (poppler/pdftoppm not installed on this machine) — only figure captions were preserved as text markers in the markdown.
