The right column of `ContentModelEditorController` is a stack of `ContentSettingsPanel`s (`editors/contentmodel`), not the old id/type/namespace/props-JSON fields. SME's panel is the `settingsRenderer` of each module in the npm package `@com.mgmtp.a12.contentengine/contentengine-editor` (`src/internal/core/default-editor-elements/<type>/<type>.settings.tsx` + `.controllers.ts`; `.../view/setting-panel/settings/*` for the shared rows) and `formengine-content-elements-editor` for form elements; download like [[a12-community-npm-and-maven-sources]] (`.../a12-community-npm/@com.mgmtp.a12.contentengine/contentengine-editor/-/@com.mgmtp.a12.contentengine/contentengine-editor-0.11.0.tgz`, note the doubled scope in the path; SME pins 0.10.0, not published). Full write-up: "Content Model property column" in `docs/sme-reference-comparison.md`; preview side: [[content-model-preview]].

**How it works:** rows in `editors/contentmodel/fields` (`ToggleRow`, `LengthRow`, `SpacingRow`, ...) are declared in each panel's FXML with `path` (dotted props path, `ContentProps` in a12-studio-models), `types` (element types) and optional `showWhen`/`enabledWhen`; `ContentSettingsPanelController` is reused by ~15 FXMLs. `types` on a row/`SettingGroup` decides which panel shows for which element type. Most FXMLs are generated by a throwaway script (not in the repo); edit them by hand now. Edits apply to the model immediately and `ContentModelEditorController` saves debounced (300 ms, flushed on close).

**Traps (each cost time):** (1) FXML attribute `opacity` on a Node subclass hits `Node.setOpacity(double)` - a custom boolean property must not reuse Node property names. (2) A `TitledPane` without a scene has no skin, so tests must walk `getContent()`, not `getChildrenUnmodifiable()`. (3) Selecting the unit that is already selected in a `LengthEditor` fires nothing (correct) - test scenarios must change unit first. (4) `AbstractPropertyEditor` persisted-expanded key is per controller class; panels sharing a controller get the FXML file name as suffix, and `isExpandedByDefault()` (new hook) makes `expanded="false"` in the FXML mean "collapsed until the user opens it". (5) `Scene.snapshot` returned a stale first frame for later selections; `Node.snapshot` was no better in a headless test - visual checks work for the first selection only.

**Paragraph/Heading text (2026-09-26):** the Content panel has a `LexicalTextRow` (no `path`) over `LexicalText` in a12-studio-models: plain text <-> Lexical `tree` + `html`, one line per block, only the differing middle of a block changes so run formatting survives, unchanged blocks are never touched. Trees with links/`ce-field-reference`/linebreaks are read-only with a hint (a flat text could not keep them). SME writes both `tree` and `html`, so both are regenerated (Lexical export shape: `<b><strong class=\"editor-text-bold\">`, `white-space: pre-wrap`). `ContentModelEditorPanelsTest` has 4 failures from before this: the committed FXML has the `elementPanel` include commented out.

**Table Columns panel (2026-09-26):** `module-row` list via `RowFactory` (label-only rows, drag handle, move/edit/delete) + `TableColumnDialogController` for all per-column settings; SME source is `default-editor-elements/table/settings/*` (`column-additional-settings.tsx` = the expandable row = our dialog, `use-drag-and-drop-options.ts` = same-pinning drop rule). The dialog edits a copy and `applyEdit` writes it back (pin change goes through `ContentTableColumns.setPinning`). Trap: `ContentModelEditorPanelsTest` is CRLF, so a Python `str.replace` with `
` anchors silently misses; and the same 5 tests fail on a clean HEAD export (element panel include commented out), not caused by panel work.

**Not built:** form-content elements (Text Line, ...), Conditional's condition editor, pickers over the Document Model for group/field ids (plain text fields now). Table-column picker built 2026-09-26: `ColumnRow` (Screen Reader Column, combo of the table's columns named by head-cell text, "None" removes the key, re-read on opening; `hint` attribute on any `SettingRow` = info icon + tooltip on the label).
